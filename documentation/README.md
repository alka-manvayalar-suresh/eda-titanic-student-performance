## Journal

**International Journal of Advanced Technology and Engineering Exploration (IJATEE)**

---

## Summary

The publication demonstrates the application of Exploratory Data Analysis (EDA) techniques to two real-world datasets: the Titanic dataset and the Student Performance dataset. It covers data preprocessing, statistical analysis, correlation analysis, and data visualization to uncover meaningful patterns and insights.
